# Sushi Market

The 'Sushi Market' is the online store of japan eat like sushi, rolls and etc.

This project has been written on PHP, Laravel on the backend and VueJS, Vuex, Axios SCSS on the frontend.

Sushi Market is very important project for me because here I dramatically improve my skills with VueJS and Vuex.

I developed the user profile pages (order list, saved addresses, favorites), user login form, modal windows with map to choose delivery address or pickup point.
